# Naked Quad

The same as a naked triple, with four cells. Suppose four cells in the same row, column or box have only four different digits among all their candidates. Four cells need four different digits, and those are the only four they can use, so the four digits go in those four cells, one each.

No other cell in that row, column or box can hold any of the four digits: remove them from the unit's other cells.

Quads are rare. When one exists, the unit's other empty cells hold the remaining digits between them, which is a hidden subset. Sometimes that is easier to spot.
